EAGLE-J CONNECT — GOOGLE LOGIN + LANGUAGE

The profile and RLS setup is included in SUPABASE-BASE-FINAL.sql. Do not run google-profile-policy.sql after the canonical migration.

To enable Google login:
1. Supabase Dashboard → Authentication → Providers → Google → Enable.
2. Add your Google OAuth Client ID and Client Secret in Supabase.
3. In Google Cloud Console, add the callback URL shown in Supabase's Google provider settings.
4. In Supabase Authentication → URL Configuration, add the production site URL and the GitHub Pages redirect URL:
   https://eagle-jconnect.github.io/eagle-j-connect/
5. Test Google login. If it fails, copy the full error message; provider credentials cannot be created by frontend code.

The language selector supports Kreyòl, English, and French and saves the selected language locally.
